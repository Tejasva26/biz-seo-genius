# CLAUDE.md

## Project Overview

Biz SEO Genius is an AI-powered SEO tool designed to help businesses
generate SEO-focused content and improve their online presence.

## Technology Stack

- React
- TypeScript
- TanStack Start
- TanStack Router
- Vite
- Tailwind CSS
- Node.js
- AI-powered content generation

## Development Conventions

- Use TypeScript for application code.
- Keep components modular and reusable.
- Use clear and descriptive names for files, components, functions, and variables.
- Keep UI components separate from business logic where practical.
- Follow the existing project structure instead of introducing unnecessary changes.
- Use Tailwind CSS for styling where it is already used.
- Avoid unnecessary dependencies.
- Do not expose API keys or secrets in source code.
- Keep environment variables in appropriate `.env` files and never commit secrets.

## AI-Assisted Development Rules

- Before making major changes, inspect the existing code and understand its structure.
- Prefer small, focused changes.
- Do not rewrite working functionality unnecessarily.
- Explain significant changes before applying them when clarification is useful.
- After making changes, check for obvious errors and consistency with the existing codebase.

## Git Conventions

Use Conventional Commits.

Examples:

- `feat: add SEO keyword generation`
- `fix: resolve content generation error`
- `docs: improve project documentation`
- `chore: update project configuration`
